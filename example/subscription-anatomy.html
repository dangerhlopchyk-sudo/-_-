Життєвий цикл запиту

  1. Користувач відкриває сайт, main.ts бере токен із localStorage.
  2. GET /api/auth/me перевіряє токен; при 401 показується форма входу.
  3. GET /api/my/subscriptions і /api/my/summary виконуються паралельно (Promise.all).
  4. API бере з Neon лише підписки власника, зсуває минулі дати на наступний період і додає daysLeft, monthlyUah.
  5. renderBlocks.ts за полем type обирає шаблон і вставляє HTML у #app.
